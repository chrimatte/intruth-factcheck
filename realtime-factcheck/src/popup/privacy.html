InTruth privacy notice

Last updated 16 July 2026

Notice version 2026-07-16-v2

In short: InTruth has no developer-operated backend, analytics, advertising, or telemetry. After you explicitly start a session, it sends data directly from the extension to the three providers for which you supply API keys.

Data sent during a session

InTruth makes the following transfers only after you start fact-checking on a supported active tab:

Data Recipient Purpose
Audio from the active tab Deepgram Live speech-to-text and speaker diarization.
Transcript excerpts and relevant page context Anthropic Identify checkable claims.
A search query derived from a claim Serper Retrieve potentially relevant web evidence.
The claim, context, and retrieved evidence Anthropic Produce a grounded fact-check result.

Each provider credential is sent only to that provider. The InTruth developer does not receive your keys or session data.

Data stored by the extension

Chrome local storage keeps your Anthropic, Deepgram, and Serper API keys, selected transcript language, and consent choice. Consent is tied to the notice version shown above, so a changed notice requires a new choice.

Chrome's memory-backed session storage temporarily holds the active session identity and capture state plus a bounded set of pending claims. A pending record can include the claim, short transcript source quotes, experimental lexical markers, and an undelivered result with cited source snippets and links. This allows safe recovery after a background-worker restart and reliable delivery of a terminal card. It is restricted to trusted extension contexts and cleared when the session stops, startup rolls back, or recovery finds no valid capture; after an unexpected failure it may remain until cleanup next runs or the browser session ends.

Fact-check cards appear in an isolated page overlay, and a session export is created only when you request it as a local HTML file.

Local Chrome storage is retained until you replace or clear the values, clear extension data, or uninstall InTruth. It is not guaranteed to be encrypted against someone with access to your device or browser profile. Use restricted, revocable provider keys where available and rotate any key you believe is exposed.

Independent providers

Deepgram, Anthropic, and Serper independently control their own logging, retention, security, and legal practices. Review their current terms and privacy notices before use. InTruth cannot inspect or delete data retained by those providers.

Using these APIs may incur charges on your provider accounts. InTruth does not control provider pricing, quotas, or limits.

Your controls

  • Choose whether to consent and start a session.
  • Stop capture from the popup; requests already accepted by a provider may still finish.
  • Clear InTruth data through Chrome's extension settings or uninstall the extension.
  • Revoke or rotate provider API keys from the relevant provider account.

Scope and changes

InTruth does not sell data, show ads, perform cross-site tracking, or capture unsupported pages. It accesses tab audio only for the active supported tab after you start a session.

Material privacy changes will update this notice version and date, the repository privacy file and changelog, and relevant product or Chrome Web Store disclosures. Report privacy or security concerns through the repository without including API keys, transcripts, or other sensitive data.
